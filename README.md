# Campus Bites

Campus Bites is a fictional university cafeteria website
developed as part of the DevOps Fundamentals assignment.

## Project Features

- Home page
- Food menu
- Daily specials and combo deals
- Ordering instructions
- Feedback and contact information

## Technologies

- HTML5
- CSS3
- Git
- GitHub

## Team

Developed collaboratively by five BS Software Engineering students
at the University of Central Punjab.
